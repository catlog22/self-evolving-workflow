# Evolve Swarm coordination

Use the exact Session and Run returned by Evolve. The Evolve database holds the roster and result receipts. Python owns the ACO assignments, history, pheromone updates and convergence under the Run's work/team directory.

1. Call evolve team controller --session <session> --run <run> to materialize the committed Python scripts. Prepare swarm-config.json in work/team and run init. Run select --iter <k> and retain the assigned ant IDs, start nodes and preferences.
2. Register each assignment with evolve team assign --session <session> --run <run> --id <assignment-id> --role <worker-id> --path outputs/ant-<iteration>-<id>.json --actor <coordinator> --expected-orchestration-revision <revision>. Dispatch the host workers with their assignment, role documents, work boundary, and the Evolve MCP connection when available. Wait for all jobs through the host.
3. Each worker opens its role from the bound revision, writes and checks its JSON, then runs evolve team report --session <session> --run <run> --id <assignment-id> --actor <worker-id> --summary "<result>" --expected-orchestration-revision <revision>. After a contention error, fetch the current revision and replay the report with a new request ID. A retry of an uncertain response uses the original request ID and payload.
4. The coordinator checks evolve team list --session <session> --run <run> and validates the assignment receipts against the controller's selected batch. A scorer uses the same roster with a path under work/team/scores/. Register and dispatch the scorer after accepting the ant artifacts. Run update after the scorer finishes and its scores cover the assigned ants. If the coordinator accepts ACO score fallback, record the failed scorer through evolve team cancel with its assignment ID, current revision and reason before passing --allow-score-fallback to Python.
5. Resume with evolve run brief and the saved team-session.json, controller assignments and roster. Reuse completed jobs and retry unfinished assignments using the original assignment identity. Re-run select --iter <k> for the persisted batch. ACO update owns score-fallback choices, commit receipts and idempotent projection of history.
6. Run converged and report, write the synthesis and declared artifacts, then seal through the Evolve Session guide. The runtime verifies that reported assignment files match their stored digests.
